# MarketScope AI

An AI-powered retail expansion strategy platform that recommends the best cities for opening new stores using demographic, economic, and competitive data.

## Features

- Expansion scoring engine
- ROI estimation
- Interactive dashboards
- AI-generated executive recommendations
- Scenario simulation

## Tech Stack

- Python
- FastAPI
- Streamlit
- SQLite
- Plotly
- Gemini API
